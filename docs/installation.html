Installation

Ein Befehl, dann läuft es.

Voraussetzungen

Ein Rechner mit Docker und Docker Compose. Für sinnvolle Antwortzeiten braucht das Sprachmodell eine passende Maschine — das ist die eigentliche Anforderung, nicht die Anwendung selbst.

Starten

git clone https://github.com/marvinhenrich/EnterpriseAI.git enterpriseai
cd enterpriseai
docker compose up -d

Danach https://<Serveradresse>:3443 aufrufen.

Was beim ersten Start automatisch passiert

SicherheitsschlüsselFür diese Installation erzeugt. Kein ausgeliefertes Standardgeheimnis.
TLSSelbstsigniertes Zertifikat, falls keines vorliegt.
DatenbankSchema wird angelegt und bei Updates mitgewandert.
AdministratorWird angelegt, Kennwort steht einmalig im Protokoll.
SprachmodellOllama läuft im selben Verbund mit.
 
docker compose logs app | grep -A3 "ERSTER ADMINISTRATOR"

Nach außen geht ausschließlich HTTPS. Die Anwendung bindet HTTP bewusst nur an die Loopback-Adresse, damit im Netz nichts unverschlüsselt unterwegs ist. Ohne Zertifikat wäre sie also gar nicht erreichbar — deshalb wird eines erzeugt.

Ollama läuft schon woanders

Dann den Dienst ollama aus der Compose-Datei nehmen und die Adresse setzen:

OLLAMA_URL=http://mein-server:11434

Wo alles liegt

Der Ordner config/ enthält alles Installationsspezifische: Konfiguration, Logo, Zertifikate, Datenbank und hochgeladene Dateien. Er wird bei Updates nie angefasst und ist das Einzige, was gesichert werden muss.

Aktualisieren

bash deploy/update.sh

Sichert zuerst config/, holt dann den neuen Stand, baut und startet durch. Bricht ab, wenn es lokale Änderungen gibt, statt sie stillschweigend zu verwerfen.
