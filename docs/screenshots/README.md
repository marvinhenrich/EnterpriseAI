# Bildschirmfotos

Alle Aufnahmen stammen aus einer Demo-Installation mit **ausschließlich
erfundenen Daten** — erfundene Firma, erfundene Personen, erfundene Vorgänge.
Der Bestand lässt sich jederzeit selbst erzeugen:

```bash
CONFIG_DIR=./demo npx tsx scripts/demo-seed.ts
```

| Bild | Ansicht |
| --- | --- |
| `01-anmeldung.png` | Anmeldung |
| `02-chat.png` | Chat mit Projektzuordnung |
| `03-projekte.png` | Projektübersicht |
| `04-wissen.png` | Wissens-Vault mit Ordnern und Notizen |
| `05-verwaltung.png` | Adminbereich, Übersicht |
| `07-auswertung.png` | Nutzung über die Zeit, Betriebsbericht |
| `08-rueckmeldungen.png` | Rückmeldungen der Nutzer |

Die Akzentfarbe der Aufnahmen (`#2F5D50`) ist eine Beispielfarbe der
Demo-Konfiguration, keine Vorgabe des Programms.
